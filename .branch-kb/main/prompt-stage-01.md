Один штрих кисти (от нажатия до отпускания) это одно изменение и одна ступень отмены. Отмена Ctrl+Z, повтор Ctrl+Shift+Z и Ctrl+Y, плюс кнопки на панели.

Цвета подбери так, чтобы виды различались между собой и на всех пяти темах; заказчик посмотрит и может попросить поменять.

По умолчанию язык браузера (`ru*` даёт русский, остальное английский); выбор в localStorage; переключение меняет все надписи без перезагрузки.

Тема это набор CSS-переменных в `client/themes.css` под `data-theme` на `<html>`; каждая переменная задана во всех темах. Холст берёт цвета пустоты, сетки и интерфейса доски из этих переменных. «Как в системе» следит за `prefers-color-scheme` через `matchMedia` и меняется без перезагрузки. Выбор в localStorage.

## Окружение Windows

- Node 22.23.2 стоит в `C:\Program Files\nodejs`, но может не быть в PATH твоей оболочки. В bash: `export PATH="/c/Program Files/nodejs:$PATH"`; в PowerShell: `$env:Path = "C:\Program Files\nodejs;" + $env:Path`.
- Временные файлы клади в короткий путь (например `%LOCALAPPDATA%\Temp\bm-...`): из очень длинного пути Windows не запускает `node`.
