## Что сделать

Всё из раздела 8.2, пункты 1..4, по правилам 5.5 и таблице 5.9 (инструменты Заливка F, Комната R, Стены W, Ластик E; кисть B). Уточнения главного агента:

- **Типы рёбер** в `catalog.ts`: `wall`, `door`, `secret`, `window`, `bars` (стена, дверь, потайная дверь, окно, решётка), знаки по 8.2 п. 3. Цвет стен и проёмов, как и цвета местности, одинаков во всех темах.
- **Проверка значений** в `store.ts`: этап 1 оставил её для `edges` и `rooms` «этапам, которые их заводят». Значение ребра только из типов рёбер `catalog.ts`; значение комнаты `1` (как в примере 6.1). Тесты на неверные значения.
