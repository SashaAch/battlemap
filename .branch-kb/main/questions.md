# Развилки

Ответ вписывается под вопросом и одновременно становится решением в разделе 3 plan.md с датой. Ответы, разошедшиеся с предложением: пока нет. В таблице этапов plan.md (раздел 10) видно, какой этап ждёт какого ответа.

## В1. Как игроки из интернета попадают на сайт, запущенный дома на Windows?

Нужен для этапа 16. На VPS и в клубной сети вопрос не стоит.

- **А. Проброс порта на домашнем роутере через UPnP**, как VPNBar открывает порт для телефонов (`~/vpn/app/PortMapping.swift`). Цена: около сотни строк по готовому образцу; нужны белый адрес и включённый UPnP на роутере.
- **Б. Виртуальная локальная сеть:** Radmin VPN, ZeroTier или Tailscale. Цена: кода нет, каждый игрок ставит программу.
- **В. Посредник на VPS.** Цена: отдельный сервис на машине с VPN; по комментарию в `~/vpn/app/Relay.swift` мобильные операторы замораживают соединения с зарубежным хостингом. Если уж есть VPS, проще поставить сайт прямо на него (этап 15).
- **Предложение:** А, первым шагом проверить белый адрес; если его нет, Б или сайт на VPS.

## В2. В каком виде сайт запускается на Windows?

Нужен для этапа 14. Язык уже решён: TypeScript на Node (Р15).

- **А. Один `battlemap.exe` (Node SEA).** Консольное окно со ссылками, сайт открывается в браузере. Цена: склейка сервера в один файл при сборке; работа `node:sqlite` внутри .exe не проверена.
- **Б. Electron.** Своё окно со значком, сайт внутри. Цена: тяжёлая сборка (размер не замерен), ещё одна сборочная система.
- **В. Папка с переносным `node.exe` и `start.bat`.** Цена: не один файл, а папка; зато никакой склейки.
- **Предложение:** А; если `node:sqlite` внутри .exe не заработает, В.

## В3. Что делает GitHub Pages?

Pages не умеет запускать сервер, поэтому учётных записей, игр и чатов там не будет.

- **А. Оставить Pages черновиком доски без сервера и витриной.** Цена: одна выкладка в CI; клиент и так умеет черновой режим.

## В7. Где хранить данные сайта?

Нужен для этапа 4.

- **А. SQLite через встроенный в Node `node:sqlite`.** Один файл `data/battlemap.db`, транзакции, запросы, копия базы одной командой. Цена: модуль помечен экспериментальным; на Node 22.22.2 работает без флагов, печатает предупреждение (проверено 2026-09-29).
- **Б. Файлы JSON по папкам.** Цена: для учётных записей, дружбы, чатов и прав доступа придётся писать самим поиск, целостность при одновременных записях и миграции.
- **Предложение:** А; весь доступ к базе только через `server/db.ts`, чтобы смена API коснулась одного файла.

## В12. Персонажи: чьи они и кто видит лист?

Нужен для этапов 11 и 12.

- **А. Персонаж принадлежит учётной записи** и подключается к любым играм, где пользователь участник. Правит лист владелец; мастер игры, куда подключён персонаж, видит весь лист и меняет хиты, временные хиты и состояния; другие игроки видят имя и полоску хитов на фишке; владелец может открыть лист друзьям на чтение, как записку.
- **Б. Персонаж живёт внутри одной игры.** Цена: для новой кампании персонажа заводят заново.
