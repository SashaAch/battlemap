# battlemap

Сайт для D&D 5e и других настольных ролевых игр, который можно поставить у себя: дома на Windows одним файлом, в клубе или на своём сервере.

- Доска: клетки по 5 футов, местность, стены строятся по контуру, нарисованному от руки, фишки противников и игроков, туман войны, обзор врагов.
- Игры, в которые можно вернуться и продолжить; учётные записи, друзья, общий и личный чат, свои записки, полный лист персонажа 5e.

Сейчас есть только план, кода ещё нет: [.branch-kb/main/plan.md](.branch-kb/main/plan.md).
