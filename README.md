# battlemap

Доска для D&D 5e и других настольных ролевых игр: клетки по 5 футов, местность, стены, которые строятся по контуру, нарисованному от руки, фишки противников и игроков, туман войны, обзор врагов. Играть онлайн: сервер работает на компьютере мастера, игроки заходят по ссылке из браузера.

Сейчас есть только план, кода ещё нет: [.branch-kb/main/plan.md](.branch-kb/main/plan.md).
